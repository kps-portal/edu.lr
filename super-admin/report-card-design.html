Designing the School-Wide Report Card Template
Everything on this card — the school identity, logo, colors, promotion policy, subject list, grading periods and grading scale — is controlled from this panel. Only a Super Admin can edit this template, and changes apply to every report card generated for the school.

Sending the Template & Controlling Who Can Grade
Super Admin sends the report card template to teachers class by class. Once sent, the teacher for that class can enter each student's grade. When grading is complete, Super Admin locks the class so no further changes can be made.
