Application-Wide Configuration
These settings control how the entire system behaves — separate from Institution Setup, which only covers the school's identity and branding. Changes here affect every portal: Super Admin, ICT, Principal, Registrar, Teachers and Students.

General Preferences

Defaults applied system-wide for every user session, regardless of role.

Inactive users are signed out automatically after this period.
User Experience
Dark Mode Available
Lets users switch to a dark color theme from their profile menu.
Show Announcements Banner on Dashboards
Displays the latest circular or announcement at the top of every role's dashboard.
Allow Users to Change Their Own Profile Photo
If off, only Registrar or Super Admin can update a user's photo.
These preferences apply immediately to every active session once saved.

Email Gateway (SMTP)

Used for report cards, admission letters, password resets and system alerts sent by email.

Use TLS Encryption
Recommended for all outgoing mail.
Send a test email to confirm your SMTP details before saving.

SMS Gateway

Used for attendance alerts, fee reminders and emergency notices sent to parents/guardians.

Enable SMS Notifications
Turn off to pause all outgoing SMS system-wide, e.g. during a billing issue.
Test messages count toward your provider's usage.

Notification Triggers

Choose which system events send an email and/or SMS automatically.

Student marked absent
Notifies the guardian the same day.
Fee payment received
Sends a receipt confirmation.
Report card published
Notifies parents once the Principal approves results.
Disciplinary action recorded
Alerts guardians of a suspension or warning.
New circular or announcement
Broadcast to the relevant audience only.
Triggers respect each channel's on/off switch above.

Portal & Module Availability

Turn a portal off to hide it system-wide (its nav item, routes and data stay intact — just unreachable) without deleting any records.

Disabling a portal here is instant for every signed-in user of that role — they'll see a "temporarily unavailable" notice instead of losing access to the app entirely.
Module changes are audit-logged with your Super Admin account.

Password Policy

Applies at password creation and reset for every account, across all roles.

0 = never expires
Require Uppercase, Number & Symbol
Enforced on password creation and reset screens.
Require Two-Factor Authentication for Super Admin & ICT
One-time code sent by email or SMS at login for the highest-privilege roles.
Force Password Change on First Login
Applies to every account created by Registrar, ICT or Super Admin.
Existing sessions are not affected until the user's next login.

Access & Login Restrictions

Coordinates with ICT's Device Management and Network Management tools.

Restrict Staff Logins to School Network / VPN
Managed alongside ICT → Network Management IP allowlists.
Allow Only One Active Session Per Account
Signs a user out elsewhere if they log in on a new device.
Log All Login Attempts to Audit Log
Feeds Super Admin → Audit Log and ICT → Security.
See ICT → Security and Super Admin → Audit Log for related detail views.

Maintenance Mode

Temporarily restrict the whole system to Super Admin and ICT while you make changes.

Enable Maintenance Mode Now
Every other role is signed out and shown a maintenance notice immediately.
Scheduling a window here does not turn maintenance mode on automatically — ICT still triggers it at the set time.

Backup Defaults

Baseline schedule used by ICT → Database Backup and Super Admin → Backups.

Store an Off-Site Copy
Mirrors each backup to secondary cloud storage, managed by ICT.
To restore a backup or view history, go to ICT → Database Backup.
