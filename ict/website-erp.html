Maintenance & Remote Actions

Clear Site-wide Cache
Purges cached pages and API responses across the public website and ERP portal so every visitor gets the latest content.
Run Site-wide Broken Link Scan
Crawls every published page and ERP module to find broken links, missing images and failed integrations.
Re-sync ERP Data Feeds
Verifies that student records, admissions and fee data shown on the website match what is recorded in the ERP database.

Danger Zone

These actions affect the live public website and ERP platform and cannot be undone remotely. Every attempt is logged with your account, IP address and timestamp.

Take a Module Offline
Immediately unpublishes a single page or module and shows a maintenance notice in its place. Enter the exact module code to confirm.
Bulk Archive Broken Pages
Marks every page or module that has been down for more than 90 days as archived and removes them from active inventory counts.
Factory Reset Entire Website & ERP Platform
Rebuilds the website and ERP platform from the last known-good deployment, wiping any unsaved content or configuration changes. Only proceed if this is a planned, school-wide re-launch event.
