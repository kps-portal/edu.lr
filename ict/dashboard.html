ICT Department — Role, Responsibilities & Relations

This describes how the ICT Administrator role fits into Kingsville Public High School's ERP — who ICT depends on, who depends on ICT, and where each responsibility lives in the system.

Core Responsibilities

  • Provision and deactivate user accounts once Super Admin or Registrar approves them (never creates accounts unilaterally)
  • Own system uptime, backups, and disaster recovery for the ERP database
  • Maintain integrity of roles/permissions so each account only reaches its own dashboard
  • Administer network, lab, and office devices (settings/devices.html)
  • Operate the SMS and email gateways used by Communication (announcements, results, fee reminders)
  • Monitor login history and audit logs for suspicious activity
  • Manage the software license and third-party API keys (payment gateway, SMS provider)

Relations to Other Roles

  • Super Administrator — approves new staff accounts; ICT provisions the login and device access once approved
  • Registrar — approves new student accounts; ICT provisions the Student ID login
  • Principal — request system-wide announcements and access-review reports
  • Bursar / Accountant — depends on ICT to keep the payment gateway and financial reports online
  • Teachers & Students — raise support requests (password resets, device faults) that ICT resolves
  • Ministry of Education — external oversight; ICT is responsible for data protection and uptime reporting

Account Provisioning Workflow

  1. Request submitted
    Super Admin (staff) or Registrar (student) creates the request in Approval Workflow
  2. ICT reviews the request
    Confirms role, department, and device/network needs
  3. System-generated credentials
    Username/Student ID + one-time password are generated — never chosen by ICT
  4. Account activated
    Person is forced to set their own password on first login
  5. Logged
    Action recorded in Audit Logs and Login History automatically
