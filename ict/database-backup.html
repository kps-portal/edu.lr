Danger Zone

These actions are irreversible and affect the entire live database. Every attempt is logged with your account, IP address and timestamp.

Restore From Backup File
Upload a .sql backup file to overwrite the current database. This cannot be undone.
Truncate All Transactional Data
Wipes attendance, grades, and finance transaction records while keeping user accounts. Intended only for a fresh academic year reset.
Reset Entire Database
Permanently deletes every record in every table. Only proceed if you have a verified, restorable backup.
