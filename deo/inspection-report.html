About this data

Every row is a live report in inspection_reports, filed either from the Inspections compose screen or by a principal via principal/inspection-report.html. Follow-up overdue means follow_up_required = true and follow_up_date has already passed. There is no explicit "resolved" flag in this schema, so an overdue follow-up stays flagged until the rating on the row itself changes.

What this page shows

Every column comes straight from inspection_reports: inspector name/title, inspection type, inspection date, term, overall rating, evaluated areas (name/rating/comments), strengths, recommendations (item/priority/target date), follow-up status, and the principal's own remarks and acknowledged name.

Overdue Follow-Ups lists reports with follow_up_required = true whose follow_up_date has passed and whose rating is still needs_improvement or unsatisfactory.

A "School" column is intentionally shown as the principal's name, not a joined institution record: this table carries no verified institution_id anywhere else in this codebase (same limitation already documented on risk-register.html and school-performance.html).

DEO can: view every live inspection report district-wide, filter by rating or type, search by inspector or principal, open the full detail of any report, export to CSV, and jump to Inspections to file a new one.
