Scope of Access & Duty of Care
This register reads live rows from inspection_reports (unsatisfactory / needs-improvement findings), suspensions (emergency removals and safeguarding-relevant offense categories), classroom_visits (needs-improvement observations still awaiting follow-up) and staff_evaluations (unsatisfactory performance ratings) — the exact tables the Principal and Teacher consoles already write to. It is read-only: record facts, preserve evidence, limit access to authorized officers, and escalate urgent safeguarding matters through the district’s approved safeguarding protocol rather than from this screen.

What this page shows

Critical = an inspection rated unsatisfactory in inspection_reports, or a suspension with priority = 'urgent' (Emergency Removal) in suspensions within the last 90 days.

High = an inspection rated needs_improvement still awaiting follow-up (follow_up_required = true), a non-urgent suspension whose offense category is one this codebase's own suspension form already treats as safeguarding-relevant (weapon_policy, substance_violation, bullying_harassment), or a staff evaluation rated Unsatisfactory in staff_evaluations.

Monitoring = a classroom visit rated "Needs Improvement" in classroom_visits that is still flagged follow_up = true and hasn't been finalized.

Safeguarding-Flagged Conduct Cases is a count of suspensions in the three categories above that are still active (no end date, or an end date today or later) — a mapping onto this app's existing offense-category taxonomy, not a formal safeguarding case log. There is no dedicated safeguarding table in this schema yet; see the handoff note before treating this figure as a certified case count.

Overdue Follow-Up Actions counts inspections with follow_up_required = true whose follow_up_date has already passed while the rating on file is still needs_improvement or unsatisfactory — a best-effort read since this schema has no explicit "resolved" flag.

"School / Area" columns are intentionally not shown for suspensions, classroom visits or staff evaluations: none of those three tables carries a verified institution_id anywhere else in this codebase (same limitation already documented on school-performance.html). Inspections show the principal's name, which the rest of the DEO console already uses as the per-school identifier.

DEO can: view every live inspection, suspension, classroom-visit and evaluation risk flag district-wide, filter and sort by level or source, export the register to CSV, and open an escalation draft — all read-only.
