Scope of Access & Duty of Care
This register reads and writes live rows in complaints (parent/community complaints) and discipline_records (serious incidents) — the two tables set aside for this workflow but not yet written to anywhere else in the codebase. Every complaint or incident must be linked to a real enrolled student from the students table. Record facts accurately, preserve evidence separately, limit access to authorized officers, and escalate urgent safeguarding matters through the district’s approved safeguarding protocol.

What this page shows

Complaints are read and written from complaints (student_id, category, description, status, handled_by, response) and Serious Incidents from discipline_records (student_id, incident_date, category, description, action_taken, status, recorded_by) — the two tables reserved for this workflow. Neither was written to anywhere else in this codebase, so every row here was filed from this screen.

Reference codes (e.g. CMP-4F21A9 / INC-4F21A9) are derived from each record's own database id, not a stored field, so they're always consistent with the live row.

Safeguarding-Flagged counts open or investigating records whose category is one this codebase's own suspension form already treats as safeguarding-relevant (weapon_policy, substance_violation, bullying_harassment) plus discrimination complaints — a mapping onto existing taxonomy, not a formal safeguarding case log.

Serious-incident categories reuse the exact 9-value offense taxonomy already shipped on principal/suspension.html, so a complaint and a suspension referencing the same conduct read the same way district-wide.

Neither table carries a verified institution_id, so no "School" column is shown — the same limitation already documented on risk-register.html and school-performance.html. Every record does carry a real student_id, shown here via the student's name and Student ID.

DEO can: register a complaint or serious incident against any enrolled student district-wide, escalate a case for further review, update a case's status as it's investigated, search/filter/sort the register, and export it to CSV.
