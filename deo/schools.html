Scope of Access
This view reads every school in the district directly from public.institutions, joined against profiles (principals and teachers), students (active learners) and today's row in attendance_daily_summary. It is read-only: the DEO can supervise and flag schools for follow-up here, but cannot create, edit or deactivate an institutions record — onboarding a new school remains the Super Administrator's responsibility.

What this page shows

Learners / Teachers are live counts of students and profiles (role = teacher, active) whose institution_id matches each school — the same join dashboard.html and teachers.html already use.

Attendance (Today) is today's row in attendance_daily_summary for that school (present ÷ total marked). A school with no attendance submitted yet today shows "—", not 0%.

Status is a simple, UI-only threshold — "Follow-up" below 80% attendance, "Pending" if no attendance is on file yet, otherwise "Active" — the same schoolComplianceLabel() heuristic already used on the Command Center. It is not an officially defined compliance formula.

A school "Type" / "Level" column and a per-school "Last Inspection" column are intentionally not shown: inspection_reports has no institution_id link anywhere in this schema yet, so a per-school inspection date cannot be shown honestly. See the handoff note before inventing one.

DEO can: view every school in the district with live enrollment, staffing and attendance, search and filter the register, export it to CSV, and identify schools that need a follow-up visit — all read-only.
