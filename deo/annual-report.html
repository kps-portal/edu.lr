What this page shows

Storage — each year's report is one JSON record in the real kv_store table, keyed deo_annual_report:<year> and scoped private (shared:false) to your own account. Nothing is stored only in your browser — it survives refresh and device changes.

Year picker — covers the current year plus the five before it. Switching years loads that year's own saved record, so you can go back and finish an earlier year's report without losing this year's draft.

Save draft vs. Finalize Report — both write to the same record. Submitting sets status: 'submitted' and stamps submittedAt, but does not notify any external account or route anywhere: there is no external delivery role defined in this codebase yet, and the notifications table's columns are inconsistent across the two places that already read it. A future pass can wire real delivery once those exist.

The Year-in-Numbers snapshot above is a genuinely live query against Supabase (schools, staffing, enrollment, attendance, marks, inspections, safeguarding, guardian coverage), read fresh on every page load — but it always reflects current data, not an archived record for whichever past year is selected in the picker. This system does not yet retain year-over-year historical archives, so treat the snapshot as reference evidence for the year currently in progress, not as certified historical data for a prior year's report.

No figures are auto-copied into the text fields below — every section is free-text you write yourself, matching how the original report form worked. Automated evidence pulls directly into the narrative would be a real feature to add later, not something to fake here.

DEO can: draft, save, and submit the annual district report for the current year or any of the five before it, entirely within their own private account — real persistence, not a demo. The live snapshot above is read-only reference evidence and edits nothing.
